# E-Commerce Storefront

## Project Overview

A fully responsive accessible e-commerce storefront built
for the Arrowstack 1-Month Frontend Internship.

## Features

- Product listing with search and category filters
- Product detail page
- Shopping cart with quantity management
- Checkout form with client-side validation
- Order success confirmation
- Accessible keyboard navigation
- Out of stock handling
- Empty state handling

## Tech Stack

- React + TypeScript
- Vite
- React Router DOM
- Lucide React (icons)

## How to Run

npm install
npm run dev
Open http://localhost:5173

## Decisions Made

- Used React with Vite instead of Next.js for simplicity
- Used Context API for cart state management
- Used URL search params for search functionality

## Known Limitations

- No real payment processing
- Data is simulated (no backend)
